# Sign Language to Voice Converter (SLVC)

## About the Project

The Sign Language to Voice Converter is an embedded system-based project designed to help speech- and hearing-impaired individuals communicate more easily with others.

The system recognizes predefined hand gestures using flex sensors and converts the recognized gestures into corresponding voice output through a speaker.

## Objectives

- To provide an alternative communication method.
- To recognize predefined hand gestures.
- To convert gestures into voice output.
- To make communication easier and more accessible.

## Hardware Components

- ESP32 Development Board
- Flex Sensors (5)
- DFPlayer Mini
- Speaker
- 16×2 LCD Display with I2C
- Battery Supply
- Connecting Wires

## Working Principle

1. Flex sensors detect finger movements.
2. The ESP32 reads the sensor values.
3. The system processes the sensor readings.
4. Predefined gestures are identified.
5. The corresponding voice output is played through the speaker.
6. The LCD displays the recognized output.

## Applications

- Communication assistance.
- Assistive technology.
- Educational institutions.
- Human-computer interaction.

## Future Scope

- Recognition of more hand gestures.
- Support for multiple languages.
- Improved gesture recognition accuracy.
- Development of a portable wearable device.
